# Practica Shop – downloads

Practica Shop is een app om opstellingen op het TTDS-practicumbord te tekenen, te simuleren en als opdracht aan leerlingen te geven.

**Nieuwste versie downloaden:** [Releases](https://github.com/practicashop/releases/releases/latest)

| Bestand | Voor wie |
| --- | --- |
| `PracticaShop-<versie>-win-x64.exe` | Installeren op je eigen pc (aanbevolen). De app werkt zichzelf daarna automatisch bij. |
| `PracticaShop-<versie>-portable.exe` | Zonder installatie, bijvoorbeeld vanaf een USB-stick. Meldt een nieuwe versie, maar vervangt zichzelf niet. |

Windows SmartScreen kan bij een niet-ondertekende installer een waarschuwing tonen: kies *Meer informatie › Toch uitvoeren*.

Alles wat je in de app bouwt, wordt op je eigen computer bewaard; de app stuurt niets naar buiten behalve de controle op een nieuwe versie.
